What it is

A world clock that stays out of the way.

Timepass is a small macOS menu bar app that shows several timezones side by side, each marked with its country flag and current time. No windows to open, no Dock icon. Just glance up.

It was built to replace older world-clock utilities that never made the jump to Apple Silicon. Timepass is written in Swift with pure AppKit and SwiftUI: no Electron, no Chromium, nothing running in the background but a clock.

Features

Everything a world clock needs. Nothing it doesn't.

Searchable picker

Type a country or city and pick its timezone from a catalog built from macOS's own tzdata.

Flags at a glance

Add as many zones as you like. Each one sits in the menu bar with its flag and local time.

Your format

Toggle AM/PM, show the date, or show the weekday, so the bar reads exactly the way you think.

Starts at login

One switch registers Timepass with macOS's modern login items, so your clocks are there every morning.

Built native

Made for the Mac, not merely ported to it.

An AppKit status item with a SwiftUI picker in a popover. It updates every thirty seconds and otherwise sits still.

Build it from source.

Timepass is open source. Three commands take you from a fresh clone to a clock in your menu bar.

  1. Clone the repository.

    git clone https://github.com/glrodasz/timepass.git && cd timepass

  2. Install XcodeGen (first time only).

    brew install xcodegen

  3. Build and copy Timepass.app into /Applications, then launch it.

    make install && make run

Requirements

  • macOS 13.0 (Ventura) or later
  • Full Xcode 15+ (Command Line Tools alone aren't enough)
  • XcodeGen via Homebrew
  • First launch: right-click the app and choose Open to approve the unsigned build.
